### The keep's bound and cost

The recency window bounds it: a start past it clears the install as
abandoned (`recencyWindow`, 6 h, `internal/updater/state.go:279`; the
decision at `:606-610`). Until then `swapAwaitingRestart` (`install.go:945`)
refuses an install of the marker's target as waiting for its restart, as it
does after a held restore, and the auto-installer takes that refusal as a
deferred state and restarts nothing (`updater.go:777-790`); a newer release
installs as before. A restart, which that refusal advises, only asks the
backup again, which does not help a backup that can never say its version
(one that cannot run, prints no version line, or whose lookup keeps
failing): the marker is then kept at every start for the whole window, and
every install of the target refused meanwhile. Round 3 (below) has the kept
line say so, and when the window ends.

1-bit-bridge

Companion server for the 1-bit iOS music player. Reach your home music library from anywhere — over Tailscale, a VPN, or a direct connection — without SMB's round-trip penalty.

Download latest release Setup walkthrough GitHub iOS app

Quick start

  1. Download for your platform

    Pre-built archives for macOS / Linux / Windows × amd64 / arm64 on the releases page. No Go toolchain required.

  2. Run bridge init

    The init wizard asks for your library path, a friendly name, and a listen address — defaults are sane. Installs as a system service so the bridge starts on boot.

    ./bridge init

  3. Pair your iPhone

    Open the admin console, install the 1-bit iOS app, and tap-to-pair from the iPhone's Discover sheet. Approve the request on the admin console — done.

For the full step-by-step including platform notes, the admin console tour, and what to do when something goes wrong: setup walkthrough.

Why

1-bit's built-in SMB transport is great on LAN but painful over high-latency links. Every pread on a remote share costs a round trip, so a library scan that finishes in seconds at home can take minutes over Tailscale's relay. 1-bit-bridge replaces SMB with an HTTP/2 protocol purpose-built for the app, plus a pre-built library manifest that lets the iOS side skip its two-phase scan entirely.

What you get

  • Pre-built library manifest served from SQLite — iOS fetches the full library (or a delta) in a single request, no walking. 50,000-track libraries sync in milliseconds. Classical metadata (composer / conductor / work / BPM) and multi-value artist credits ride along.
  • Bit-exact, no transcoding ever. FLAC, ALAC, WAV, AIFF, MP3, AAC, DSF, DFF — served as-is. iOS still pre-caches the full DSF / DFF before playback so the DAC's DoP lock isn't at risk.
  • Tap-to-pair from iOS with admin approval, or generate-token-and-scan-QR for power users. Bearer tokens per device, rotatable, revocable.
  • Tailscale-ready with three integration modes — embedded tailnet node (zero CLI dependency), system-CLI passthrough, or LAN-only.
  • Optional offline PCM upscaling via sox for high-end DACs that benefit from upsampled material — opt-in, off by default. Variants are managed from a folder-first Library Inspector in the admin console.
  • HTTP/3 (QUIC) on the same port as HTTP/2 — iOS picks the better transport on lossy cellular links, no operator-side configuration needed.
  • Public-internet deployment mode (v0.1.4) for bridges intentionally exposed beyond the LAN — adds a password-protected admin console and native Let's Encrypt cert provisioning via ACME, on top of the same paired-token-authenticated iOS API.
  • DLNA / UPnP MediaServer, playlist backup, and opt-in listening history (v0.1.5) — optionally serve your library to LAN renderers like the Chord 2Go, back up your iOS playlists so they survive a reinstall, and keep a private listening log that never leaves your machine. All off or opt-in by default.

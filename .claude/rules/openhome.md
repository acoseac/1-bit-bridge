# The player's OpenHome surface (B470 PR 5a2a on)

> Each long entry here is one line, its bold title plus its own bolded "Don't…/Never…" sentences and the tests that pin it, ending `→ History-rules-openhome.md`: that is `ops/History-rules-openhome.md`, where the entry sits whole with its reasoning, measurements and rejected alternatives. **Still binding.** Edit the line here and its long form there in the same commit.

What an OpenHome controller talks to: the opt-in, the player's own LAN listener, admission and limits, the Source's device and service descriptions, the SOAP layer, the read actions and GENA's refusal (`internal/player/openhome`; the served addresses from `internal/player/lan`; serve's start and stop of it in `cmd/bridge/serve_player_openhome.go`). The player's engine, backend and serve wiring are `player.md`'s. SSDP discovery is PR 5a2b's (`discovery.go`); the read actions are PR 5a3's (`actions.go`), the writes PR 5a4's (`writes.go`, `inventory.go`), with an Insert's confinement (the canonical URI, `internal/player/trackref`; the library's membership check, `internal/player/library`'s `Member`, its index built ahead of the first Insert by `Warm`). The records are in `ops/engineering-log.md`: 2026-10-23, B470 PR 5a2a; 2026-10-24, B470 PRs 5a2b, 5a3 and 5a4; 2026-10-25, PR 5a4's library index built ahead of the first Insert.

## The player's OpenHome surface (B470 PR 5a2a)

- **`output.player.openhome` is the opt-in, off by default, and it stays off by default until the owner decides it after B470 5b and 5c**: 1-bit 2.1 and earlier never probe a host that advertises an OpenHome Source for MPD, so there the Source takes the box's MPD row away (1-bit 2.2 lists both: the iOS repo's B550); PR 5a4's writes make the Source castable, and since B612 (2026-10-31) the console's Player page sets it (`POST /api/output/player/openhome`, admin-console.md), asking the port of the config it saves whatever `enabled` says (`config.OpenHomePortClash`): an opt-in turned on with the player off is saved, and a clash is refused, nothing written. Serve reads it once, from the boot snapshot (`planServePlayer`): a player that starts starts the surface after launching its engine (without an engine-readiness gate), a player that does not start starts none of it, and with the opt-in on and the player simply off (`enabled: false`) nothing of it runs and boot says so once. `openhomePort` is 7792 (`DefaultOpenHomePort`, after 7788 to 7791) or 0 for a port the kernel picks per address; it is validated like its neighbours (a word, a list or a fraction leaves the block unread (a fraction read as its whole part until B528), a number outside 0 to 65535 is `Problem`'s refusal), and with the surface on a port another listener of serve binds (`listenAddress`'s, `adminAddress`'s, `dlna.listenAddress`'s whether or not DLNA is on, `output.loopbackPort`'s; an empty address its default; 0 clashes with nothing) turns the player off in `PlayerEnabled` at the start that reads it, naming that setting and never the port. A running serve's player judges that clash on its boot snapshot alone (`config.PlayerEnabledAsBooted`: the watcher's settings, serve's player's withholding, the console's view), whose listeners and surface are the ones bound, so a live opt-in or address waits for the next start; and while the opt-in is on, the console's settings save refuses a listener address on the port (409 `openhome-port-clash`, nothing written), so the next start finds none (B612's second round). **Don't turn it on by default before 5b and 5c, read it live, run any of the surface while the player does not, quote a port in a refusal, save the opt-in on over a clash, whatever `enabled` says, judge a running player's clash on the live config, or save a listener's address onto the port while the opt-in is on.** `TestTheOpenHomeSurfaceIsOffByDefault`, `TestTheOpenHomeOptInLoadsAndRoundTrips`, `TestAnOpenHomeSettingIsValidatedLikeItsNeighbours`, `TestAWholeNumberOfThePlayerTakesNoFraction`, `TestAnOpenHomePortServeBindsElsewhereTurnsThePlayerOff`, `TestServeRunsTheOpenHomeSurfaceOnlyWithItsOptInAndThePlayer`, `TestTheOpenHomePortClashIsAskedWhateverThePlayerSays`, `TestTheOpenHomeSwitchRefusesAPortAnotherListenerBinds`, `TestTheConsolesOpenHomeSwitchLeavesWhatPlaysAsItIs`, `TestTheRunningPlayersOpenHomeClashIsJudgedOnItsBootSnapshot`, `TestALiveClashWithTheOpenHomePortLeavesTheRunningPlayerAsItIs`, `TestTheConsoleRefusesToMoveAListenerOntoTheOpenHomePort`, `TestASettingsSaveTheNextStartWouldRefuseIsRefused`, `TestTheNextStartRefusesThePlayerOverAClashEditedIntoItsFile` and serve's gate row "an OpenHome port serve binds already" pin it. → History-rules-openhome.md
- **The surface is a listener of its own: one IPv4 socket per address `lan.Look` serves, never a wildcard and never on DLNA's listener, keyed by `lan.Address` (the address, its on-link prefix, its interface's name and index), followed by a listing every 5 s.** An address that appears is bound; one that goes away, changes its prefix or its interface's index, or stops being eligible has its socket and its connections closed, the listener closed by the surface itself as well as by its server's `Close` (which closes only what `Serve` has begun to track), and leaves `Status` only once its connections are closed (B557: `retire` marks it retiring, so its `Serve` goroutine does not mark it ended, closes its listener, waits for that goroutine, then closes its connections, and the listing drops it after); a listing that fails keeps what is bound; a bind that fails fails that address alone, is said once, and is tried at the next listing, never reaching serve or the library. **Don't mount the player on DLNA's listener, whose guards serve every LAN address to any source, bind a wildcard, key a socket without its interface's index, close what is bound on a listing that failed, leave a retired socket's listener to its server's Close, or let `Status` stop listing a retired address before its connections are closed.** `TestTheSurfaceBindsEachServedAddressAndFollowsThem` (each retirement held at `Seams.Retiring`), `TestABindFailureFailsThatAddressAlone`, `TestEveryURLCarriesThePortTheRequestArrivedOn`, and lan's `TestLookKeepsEachServedAddressWithItsPrefixAndInterface` and `TestAnInterfaceAddressBecomesItsOwnPrefix` pin it. → History-rules-openhome.md
- **Admission is at accept, before any cap counts: the socket's own address while the listing serves it, and an approved source, an IPv4 address inside the on-link prefix of the address the connection arrived on, of the LAN's classes (`lan.IsLANAddress`), never loopback and never one of the box's own addresses; then each request's Host must be exactly that address and port, or it is 400.** A refused connection is closed at once (linger 0), unread and unanswered, counted against nothing, and logged once per kind and source (32 at most); the kinds are `destination_not_served`, `source_not_ipv4`, `source_loopback`, `source_own_address`, `source_outside_prefix` and `source_not_lan`. **Don't count a refused connection, answer it, admit a source by another address's or interface's prefix, by a prefix wider than its address's class, from loopback or from any address the box holds, elide a default port, or move the check into a handler.** `TestAdmissionRefusesAtAcceptAndCountsNothing`, `TestAConnectionOnAnAddressNoLongerServedIsRefused`, `TestTheCapsCountOnlyAdmittedConnections`, lan's `TestIsLANAddressIsTheEligibleClasses`, the table's row-1 rows and `TestOptionsStarPassesThroughTheSurface` pin it. `DisableGeneralOptionsHandler` keeps `OPTIONS *` in this handler: the Host check, route refusal, stop refusal and empty EXT still apply. → History-rules-openhome.md
- **The arrival interface is restricted where an unprivileged option exists: `SO_BINDTOIFINDEX` on Linux (an unprivileged process may set it since 5.7; refused, the socket listens unrestricted and says why), `IP_BOUND_IF` on macOS (measured: it scopes what the socket sends and does not refuse a segment by the interface it arrived on), nothing elsewhere.** IPv4 on Linux is the weak host model; a handshake from outside the prefix needs a route back, so a source in the prefix and a served destination refuse what they must in the ordinary case. The residual: a router on the LAN that rewrites sources into the prefix (SNAT), and anything on the link that holds an address in it, is admitted. **Don't require a privilege for the restriction, fail a bind over it, bind index 0, or say IP_BOUND_IF filters what a socket receives.** `TestEachSocketIsRestrictedToItsInterfaceWhereThePlatformLets` pins it. → History-rules-openhome.md
- **The limits (`DefaultLimits`): 32 connections and 8 per source, counted after admission; 8 slots, taken once a request's body is read, 503 at once past them; deadlines for the header (5 s), the whole request (10 s), a control body's own (5 s, set once rows 2 to 5 pass), the write (10 s from the request's headers) and an idle connection (30 s); 16 KiB of headers; 256 KiB of body.** **Don't take a slot before the body is read, block a request waiting for a slot, leave a write without its deadline, or lean on the whole request's deadline for a body or a header.** `TestATrickledBodyMeetsItsDeadlineHoldingNoSlot`, `TestAClientThatStopsReadingIsCutOffByTheWriteDeadline`, `TestTheSlotsAnswer503AtOncePastThem`, `TestAHeaderPastItsBoundIsRefused`, `TestAnIdleConnectionAndAStalledHeaderAreClosed` and `TestTheCapsCountOnlyAdmittedConnections` pin it. → History-rules-openhome.md
- **The stop refuses every request after it (503, its connection closed), withdraws discovery while HTTP remains bound, joins the listing loop, closes each listener and shuts each server down within its grace (2 s), closes what is still open, then joins the Serve goroutines and the handlers within its bound (1 s), counting what is left; serve's player stops the surface first, before its engine.** **Don't stop the engine before the surface, wait on a request past the grace, skip the refusals, report a stop that left a handler running as clean, or mistake an already-closed listener for an expired grace: only Shutdown's context deadline or cancellation marks it forced.** `TestStopRefusesThenShutsDownThenCloses`, `TestAStopWithNothingUnderWayIsQuick`, `TestARequestAfterTheStopsJoinIsRefusedLikeEveryReply`, `TestIdleSocketsNeverMakeACleanStopForced` and the direct Run-liveness observation at `Seams.Stopping` in `TestServeRunsTheOpenHomeSurfaceOnlyWithItsOptInAndThePlayer` pin it. → History-rules-openhome.md
- **A panic in the surface's listing (the address source's or its own) stays in the surface: recovered in the loop, it ends the following and withdraws discovery, retaining the bound HTTP surface, and the line carries the stack and never the panic's value, unless it is the runtime's own error.** **Don't let the loop's panic reach serve, or log a panic's value.** `TestAPanicInTheListingStaysInTheSurface` pins it. → History-rules-openhome.md
- **Only `/openhome/` is served: the device description at `description.xml`, built per request with every URL absolute on the address and port the request arrived on; each service's `scpd.xml`, `control` and `event` under `/openhome/<service>/`; 404 for any other path, no admin, `/v1`, media or CORS.** The description is an OpenHome Source (`urn:av-openhome-org:device:Source:1`), its UDN `uuid:` and the player's UUID, never the MediaServer's, manufacturer `1-bit`, manufacturerURL `https://1-bit.app`, modelName `1-bit Bridge Player`, modelNumber the bridge's version, modelDescription `The 1-bit bridge's own player` (neither of upmpdcli's strings), no serialNumber, and the four services (Product, Playlist, Info, Time; no Volume), each with its type and ID (`urn:av-openhome-org:serviceId:<name>`). **Don't mount anything else on the surface, add CORS, give a relative URL or another address's, name the MediaServer's UDN, add a serialNumber, or add Volume while the output is fixed.** `TestOnlyOpenHomePathsAreServed`, `TestTheDeviceDescriptionIsTheSourcesOwn`, `TestTheModelDescriptionIsNoOneElses`, `TestTheSourceCarriesFourServicesAndNoVolume` and `TestEveryURLCarriesThePortTheRequestArrivedOn` pin it. → History-rules-openhome.md
- **The friendlyName is `output.player.room` from the boot snapshot, or `1-bit Bridge Player`: what XML 1.0 cannot carry dropped, cut to 64 runes on a rune boundary, then escaped; a room that keeps nothing is the default.** **Don't cut a rune, trust config's validation of the room here, or let the name be empty.** `TestTheFriendlyNameIsTheRoomAsXMLCanCarryIt` pins it. → History-rules-openhome.md
- **The four SCPDs are the bridge's own tables (`services.go`), generated, and compared exactly with OpenHome's files at ohNetGenerated 22feef52, which are test data with their MIT licence and never built into a binary.** **Don't embed, ship, edit or regenerate the upstream files, or change a table without the comparison passing.** `TestOurSCPDsAreUpstreamsInventory` and `TestTheUpstreamFilesAreTheirPinnedBytes` pin it. → History-rules-openhome.md
- **The SOAP layer checks a control request in the table's order below, one outcome a row; a request that passes is its action's to answer, 501 while no engine runs, asked first: a read from one snapshot of the engine (`actions.go`, "The read actions" below); a write by its writer within its budget (`writes.go`, "The write actions" below).** A fault is HTTP 500 with `s:Client`, `UPnPError`, its code and description (UDA 1.1, §3.2.2: 401, 402, 501, 600 and 605, each with its source in `soap.go` and `writes.go`; 602 is no longer defined, since PR 5a4 no action answers it; and OpenHome's codes, Playlist's 800 to 804, Product's 801 and 899, each with ohPipeline's description), or `s:MustUnderstand` with no detail (SOAP 1.1, §4.4); every reply carries an empty `EXT`, written as `EXT`; a control request refused before its body is read has its connection closed; nothing is trimmed. **Don't reorder the rows, read the body before rows 2 to 5 pass, trim a typed value, or define a UPnP code without its source.** `TestTheSOAPTableRowByRow` (a test per row and each row's edges), `TestTheBoundsArePinnedWhereTheTableSaysTheyAre`, `TestAnOriginIsRefusedBeforeTheBodyIsRead`, `TestEveryValidActionIsAnswered602NoMore` (every write answered by its writer, never 602: with no engine 501, with one that plays a response or a fault of its own), the refused Insert in `TestServeRunsTheOpenHomeSurfaceOnlyWithItsOptInAndThePlayer`, `TestValueOfTypeIsUPnPs` and `FuzzControlRequest` pin it. → History-rules-openhome.md
- **GENA is 501 Not Implemented for SUBSCRIBE and UNSUBSCRIBE at every eventSubURL, with no SID or TIMEOUT, and 405 for any other method there: never 200, so no controller holds a subscription.** **Don't answer 200, hand out a SID, or answer 503.** `TestGENAIsRefusedAndNoSubscriptionIsHeld` pins it. → History-rules-openhome.md
- **The surface's tests run it on `lantest`'s loopback box and serve's hand it a box (`serveOpts.playerOpenHome`); in cmd/bridge's suite `hostLAN` is a box with no interface.** **Don't bind a host's LAN address in a test, list the host's interfaces there for anything but its loopback, or order a stop or a retirement with a sleep.** The "no box of the test's" case of `TestServeRunsTheOpenHomeSurfaceOnlyWithItsOptInAndThePlayer` pins it. → History-rules-openhome.md

- **Serve validates `--addr` with `config.ValidateBindAddress` before planning or taking the data-directory lock: service names, empty ports and ports outside the TCP range are refused, without quoting the override. A numeric override that creates an OpenHome clash turns the player off and logs its new reason once, naming `listenAddress, set by --addr` without quoting a value; a refusal unchanged from Load stays already reported (the plans compare reason strings).** `TestServeRefusesANonnumericAddressOverrideBeforePlanning`, `TestServeSaysOnceWhenAnAddressOverrideClashesWithOpenHome` and `TestServeDoesNotRepeatAnUnchangedRefusalUnderAnAddressOverride` pin it. **Don't assume that Load reported a refusal created by an override, repeat an unchanged refusal under an override, or blame the file alone for an address set by --addr.** → History-rules-openhome.md

## Source discovery (B470 PR 5a2b)

- **The Source registers with serve's one SSDP subsystem after HTTP enters Serve on a bound listener, independently of DLNA and engine readiness.** Seven ordered targets: rootdevice, player UDN, Source:1, then Product/Playlist/Info/Time:1 from `services.go`; SERVER is the bridge token without DLNADOC; every LOCATION uses that listener's bound port. **Don't use Start's return or player.ready as success, advertise an unbound address, reuse the MediaServer's identity/port, or enable the opt-in by default.** `TestSourceDiscoveryIdentityAndSearches`, `TestSourceWaitsForBoundHTTPAndRepeatsItsTargets`, `TestServeSharesDiscoveryAcrossItsEligibleDevices`. → History-rules-openhome.md
- **Discovery follows serialized whole address transactions, with immutable bound-endpoint and Own snapshots and the same source-only admission as TCP.** Bind and enter Serve before adding; withdraw removals before closing; prefix/interface replacement is withdrawal/close then bind/add; survivors re-alive. Empty means Withdraw and clear the handle; failures retry at the next listing, including unchanged snapshots; listing error keeps the last good inventory. Interface lives start at 0, shared by aliases, advance only on observed absence. **Don't hold surface locks across SSDP I/O, reuse a withdrawn handle, admit another alias's prefix, keep Own stale, or claim identical recreation between polls is detectable.** `TestSourceAdmissionUsesTheCurrentBoundInventory`, `TestSourceDiscoveryFollowsAddressTransactions`, `TestSourceDiscoveryRetriesHTTPAndSSDPWithoutAddressChanges`, `TestSourceRemovalWithdrawsBeforeRebinding`, `TestSourceRefusalsAcquireNoReplySocket`. → History-rules-openhome.md
- **Refuse freezes publication and answers 503 before withdrawal; StopContext joins discovery before HTTP's separate bounded stop, and the player joins HTTP before its engine.** Source lifetime cancellation stops normal sends, not byebye; a Register context lives as long as its handle. Unexpected HTTP exit clears discovery admission and cancels the registration lifetime, even during Register/Update, then joins pending normal writes through its SSDPSendBarrier outside publication locks; completion permits no later alive/reply from that lifetime. Reconciliation withdraws it and registers the current bound listeners with a fresh barrier. Listing/supervisor exit withdraws; late bind/Register/Update completion cannot revive a stopped generation. **Don't cancel a successful Register's context as an operation timeout, close HTTP before byebye, suppress byebye on cancellation, or replace the shared absolute SSDP deadline with a fresh budget.** `TestSourceWithdrawsBeforeHTTPCloseAndRefusesWhileParked`, `TestSourceStopWinsAStalledBind`, `TestSourceStopWinsInFlightDiscovery`, `TestSourceDiscoveryEndsWithItsSurfaceGeneration`, `TestSourceHTTPExitCancelsPendingAdvertisement`, `TestSourceHTTPExitJoinsAnAliveAlreadyWriting`, `TestServeWithdrawsSourceBeforeStoppingItsEngine`, `TestServeDiscoveryRestartsWithStableIdentity`. → History-rules-openhome.md

## The read actions (B470 PR 5a3)

- **Every read is answered from one snapshot of the engine that the request takes, never a command and never a wait on the owner; while no engine runs (none given, its Run returned or a panic ended it, its shutdown begun: `Done` asked once the snapshot is taken, then `Closed`) every action is fault 501 (Action Failed, UDA 1.1 §3.2.2), asked before anything else a write does.** The reads are the 25 actions that change nothing (`reads`), the writes the other 17 (`writes`, PR 5a4's, "The write actions" below); serve hands the surface the engine its player runs (`openhome.Config.Engine`, `startOpenHome`). The restored identity's policy is in place (B470 PR 5a0, #1331: a backup carries the reservation, and a restore raises both marks past anything the snapshot's identity handed out), so a restored identity's reads hand a controller none of its source's IDs or tokens. **Don't answer an action from an engine that has ended, issue an engine command from a read, or take two snapshots for one reply.** `TestTheReadsAndTheWritesAreEveryAction`, `TestEveryValidActionIsAnswered602NoMore`, `TestNoEngineIsOneFaultForEveryRead` (none given, a Run ended, a shutdown begun, a panic; every read and every write), `TestTheSurfaceAnswersReadsFromItsEngine`, `TestARestoredIdentityHandsOutValuesPastItsSnapshot` (a restore onto a fresh data directory) and the IdArray and TransportState reads in `TestServeRunsTheOpenHomeSurfaceOnlyWithItsOptInAndThePlayer` pin it. → History-rules-openhome.md
- **TransportState is the engine's transport as one of the four words the SCPD allows: Playing, or Buffering while nothing of a starting session is audible (`Starting`); Paused; Stopped; a release by what follows it (stop Stopped, pause Paused, play Buffering); maintenance Stopped.** **Don't answer another word: 1-bit refuses any but the four.** `TestTransportStateIsTheEnginesTransport` (every state, starting or not, and intent; and through the engine, each it reaches) pins it. → History-rules-openhome.md
- **The queue's reads: Id the selection (0 for none; after the selection's deletion the entry that followed it, none after the last, as ohPipeline re-points); Read the entry's reference and metadata byte for byte, fault 800 (OpenHome's, the engine's `ReasonIDNotFound`) for an ID the queue does not hold; ReadList a TrackList, an Entry (Id, Uri, Metadata) for each ID held, in the order and as often as asked, an ID not held left out (ohPipeline's `ProviderPlaylist.cpp`, line 389), its IdList decimal ui4s by row 9's rule separated by XML's white space anywhere, a token that is no ui4 fault 402, more IDs than `engine.MaxReadList` or a TrackList past 8 MiB, its closing tag counted, fault 605 (String Argument Too Long), each entry read and escaped one at a time; IdArray the token and the IDs from one snapshot, big-endian ui4s in base64; IdArrayChanged whether a token differs from the queue's; TracksMax `MaxEntries`; Repeat; Shuffle 0.** Read answers the entry's reference, the Uri exactly as the controller inserted it (PR 5a4; round 3 restored it after round 2 stored the canonical form), or a bare track id an entry written before keeps, so Read returns what was inserted (1-bit matches it exactly). **Don't fault a ReadList for an ID it does not hold, take a token that is no ui4, answer past either bound, leave the TrackList's closing tag out of its bound, copy every entry before the bound is checked, take the token and the IDs from two snapshots, or write the IDs little-endian.** `TestIdReadAndReadListFollowTheQueue`, `TestReadListTakesWhiteSpaceAndRefusesWhatIsNoID`, `TestReadListIsBounded`, `TestTheTrackListBoundIsItsWholeDocument`, `TestIdFollowsADeletedSelection`, `TestIdArrayIsTheTokenAndTheIDsInQueueOrder`, `TestTracksMaxRepeatShuffleAndProtocolInfo` and `TestOneBitsCastStartAndPoll` pin it. → History-rules-openhome.md
- **Time and Info read the occurrence heard (`engine.Snapshot.Track`): Duration the decoder's exact length (the backend's report: total frames over the rate) rounded to the nearest second, a half up, never the controller's metadata or the index's tag; Seconds the whole seconds of its position (floor), 0 while nothing of it is measured; TrackCount one per occurrence heard since the engine started; DetailsCount one per change of what the backend reported; Details the PCM bit rate (rate × bits × channels), the bits, the rate, lossless and the codec; Track the occurrence's reference and metadata as it was handed off; nothing heard reads zero and empty; every Time value, and Info's Duration, held to 10,000,000, which 1-bit reads at most.** **Don't take a length from metadata, round Seconds, floor Duration, answer a Time value past 10,000,000, or read the next entry's values under a deleted one's occurrence.** `TestTimeAndInfoReadTheTrackHeard` (a restart's zeros included), `TestADeletedAudibleEntryIsNoLongerHeard`, `TestTheTimeIsHeldForOneBit` and `TestOneBitsCastStartAndPoll` pin it. → History-rules-openhome.md
- **Product describes the one Source: the vendor and model the description names, Room the friendly name, never in standby, one source `Playlist` at index 0, SourceXml in OpenHome's SourceList form (Name, Type, Visible true, SystemName), Source of any other index fault 801 (Source not found), Attributes `Info Time`, SourceXmlChangeCount 0; and Playlist's ProtocolInfo lists FLAC, WAV, AIFF and ALAC in M4A, each with the type internal/dlna serves the file as, for every renderer profile.** The codes, their descriptions and the forms are ohPipeline's, read at master c1047a8dc801: Source's 801 (`FaultCode.cpp` line 21, answered at `ProviderProduct.cpp` 284), Read's 800 (`ProviderPlaylist.cpp` 23-24, the engine's own mapping too), the SourceList (`Product.cpp` 299-317) and the Attributes (209-215). Booleans are 1 and 0 (UDA 1.1, §2.5). **Don't list a source or a type the player does not play, or answer standby.** `TestTheProductReadsAreTheSourcesOwn` and `TestTracksMaxRepeatShuffleAndProtocolInfo` pin it. → History-rules-openhome.md
- **Every string of a reply goes through one escaper (`escapeTo`, xml.EscapeText), once at each level of a value that is XML itself (SourceXml; ReadList's TrackList, and the Metadata inside it), so a value that is XML 1.0 text reads back byte for byte and one that is not still makes a well-formed reply, each character XML 1.0 cannot carry sent as U+FFFD; a response carries a Content-Length, counted before it is written.** Since PR 5a4 Insert refuses a Uri or Metadata that is not XML 1.0 text (the Uri is ASCII by its canonical form, the Metadata by `metadataFault`), so no value it stores needs the replacement (encoding/xml refuses such a character at row 7, literal or referenced, but decodes a surrogate's reference to U+FFFD and a literal carriage return to a line feed: the stored value is the decoded one). **Don't write a value unescaped, escape a nested value only once, or send a character XML 1.0 cannot carry.** `TestEveryValueRoundTripsThroughItsEscaping`, the room of `TestTheProductReadsAreTheSourcesOwn` and `FuzzControlRequest` (every response parses, its nested values too) pin it. → History-rules-openhome.md


## The write actions (B470 PR 5a4)

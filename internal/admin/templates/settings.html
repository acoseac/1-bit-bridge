Networking

What iOS clients dial, e.g. :7788.
Must be a loopback address (127.0.0.1, ::1, or localhost). Non-loopback values are rejected — the admin console has no auth.
One https:// URL per line. Use this for reverse proxies, port-forwarded WAN URLs, or Tailscale MagicDNS names the auto-detector didn’t pick up. Each line must be a complete URL including port. Non-HTTPS or malformed entries are silently dropped on save. For iOS clients to actually reach a custom URL, the TLS certificate’s SAN list must cover the URL’s hostname or IP — change the list, then rotate the cert and re-pair iOS devices.

Updates

The bridge polls the GitHub Releases API for new versions. Operator-triggered install is always available on the dashboard; auto-install is opt-in.

When enabled, every successful poll that surfaces an update triggers download → verify → atomic swap → restart, subject to the same active-stream gate as the manual Install button. Default off — opt-in is recommended even on stable channels.
Restricts auto-install to a daily window in server-local time. Leave empty to permit any time. Wraps midnight (e.g. 23:00-06:00) for overnight schedules.
How often to poll the GitHub Releases API. Defaults to 6 (4 polls/day, well under the 60/hr unauthenticated rate limit). Lower values are clamped to a 1 h floor at runtime.

Reachable endpoints

Addresses this bridge advertises to paired iOS devices. Devices try them in order and stick to whichever connects. The list is recomputed live from network interfaces — bring a Tailscale tunnel up and refresh to see the new entry.

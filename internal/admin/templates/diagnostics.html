Deleting rows — duplicates, missing tracks, emptied trash — leaves gaps behind. SQLite reuses them but never returns them to the filesystem on its own. Compacting rewrites the file and hands the space back.

The figure above is a floor, not an estimate. It counts only pages that are completely empty; compacting also repacks the partly-used ones, and deleting scattered rows leaves plenty of those and no empty pages at all. A database showing no whole free pages can still shrink by half.

It takes an exclusive lock for the duration, so the bridge will stall for other requests while it runs, and it needs twice the current file size free while it works. Refused outright while a library scan is running.

Export logs

Checking for a log file…

Replaces absolute filesystem paths and non-loopback IPs. Library-relative paths and loopback addresses are kept, because they identify nobody and are usually the reason the line is being read. This is a courtesy pass, not an anonymiser — read the file before posting it somewhere public.

The bundle is one pasteable text file: version and platform, the counters on this page, the preflight results, and the last 24 hours of log. It is redacted by default — it exists to be sent somewhere.
